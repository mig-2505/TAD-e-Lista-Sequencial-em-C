# TAD Aluno e Lista Sequencial em C

## 📋 Descrição
Este projeto implementa um Tipo Abstrato de Dados (TAD) Aluno e uma Lista Sequencial em linguagem C, com o objetivo de exercitar conceitos de modularização de código, manipulação de structs e controle de versões com GitHub.

O trabalho é dividido em etapas colaborativas: cada aluno cria uma branch própria para implementar um dos exercícios e depois envia um Pull Request para integrar na main.

## 📁 Estrutura do Projeto
tad-aluno-lista-c/

├── aluno.h        # Definição da struct Aluno

├── aluno.c        # Funções relacionadas ao Aluno

├── lista.h        # (opcional) Cabeçalho da Lista Sequencial

├── lista.c        # Funções de manipulação da Lista Sequencial

├── main.c         # Programa principal para testes

└── README.md      # Este arquivo

## 💻 Como Compilar e Executar
```bash
git checkout main
git pull origin main

gcc main.c aluno.c lista.c -o programa
./programa
```
